连续性系统—品种历史波段趋势识别与强度评分
任务需求：对单一品种（指数、板块、商品等）自动识别历史波段（基于点数波动分档），对每个波段进行趋势连续性评分，并输出波段趋势质量评分
主要实现核心功能如下
1. 波段自动识别：基于价格低点→高点涨跌点数，按品种历史分位数自适应划分波段级别（如小/中/大/超大），输出起止日期、涨跌点数/幅度、持续天数。
2. 波段趋势性评分：综合强度（涨跌幅）、持续时间、斜率、回撤控制、量能配合等，输出0-100分及维度拆解。
3. 波段对比：按级别筛选并按得分排序；支持两个波段走势对比及指标对比；当前波段与历史同级别波段对比，输出历史分位。


对每个品种(指数、板块、商品等内部指数)，以上证指数为例,
识别波段，300点以下(多数为震荡)、300-500,500-800,800-100.1000点以上(暂
定，每个品种都不一样，这个可以细分考虑，比如先识别各个波段的min-max点数，然后
根据点数的波动性不同，每个品种根据分位数，近似取整)
区分不同波段的趋势连续性对比
比如有些波段趋势猛、时间短，有些时间长，度缓
然后对这些波段进行多维度的评级(持续时间、强度等)，评价其趋势性得分

# 连续性定义
严格连续性:指连阳、连阴等严格连续形态，主要用于判断当前价格路径是否保持
连续。严格连阳以 K 线实体为正为连续条件，严格连阴以 K 线实体为负为连续条
件;中间一旦出现相反实体，则严格连续性中断。
区间连续性:指用户自选一个起止区间后，在该区间内比较指数的连续性和强度
区间连续性不要求每天都严格连阳或连阴，允许中间出现回调、反弹或相反 K线
重点看区间内的方向一致性、累计涨跌幅、趋势斜率、回撤控制、波动稳定性、量
能配合等综合表现.
说明:非严格意义上的“连阳/连阴”统一归入区间连续性。例如在指数分析中，用户自选
某一时间区间后，系统需要横向比较多个指数，找出该区间内连续性最强、强度最高的
指数。

# 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

# 数据刷新

看板运行时只读本地 CSV，不会联网拉取数据。刷新本地数据时设置 `TUSHARE_TOKEN`，再运行：

```bash
python scripts/refresh_data.py --group index
python scripts/refresh_data.py --group sector
python scripts/refresh_data.py --group commodity
```
